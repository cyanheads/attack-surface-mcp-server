# 0.4.0 — 2026-10-16

## Changed

- **`attacksurface_recon_guidance.nextToolSuggestions`** replaces `tool`, `server`, `arguments` and `rationale` with `toolName`, `reason` and `args`; executable suggestions target registered local tools, while product/version advisory checks remain in priorities and text. [#12](https://github.com/cyanheads/attack-surface-mcp-server/issues/12)
- **Enumeration counts** replace populated `totalCount` with `discoveredCount` and remove global `liveCount`; `returnedCount` describes the current page. `pageInstructions` replaces `notice` with empty-result and continuation guidance. [#32](https://github.com/cyanheads/attack-surface-mcp-server/issues/32)
- **Enumeration and guidance pages** default to 50 records and target 24,000 serialized bytes across both surfaces, with explicit complete-record exceptions. Enumeration caps DNS work before resolving; guidance uses independent offsets and a concise `plan` with detailed actions in `priorities`.

## Fixed

- **Map guidance handoff** prefills local triage arguments from TLS, audited missing headers, versioned technologies and observed ports, preserving false/zero evidence and omitting unknowns; bounded host coverage names exact omissions. [#13](https://github.com/cyanheads/attack-surface-mcp-server/issues/13)
- **Guidance topics** select triage, TLS/header posture or inspection/version coverage before paging and severity ordering; observed ports add informational inventory review, and absent evidence reports unknown coverage. [#33](https://github.com/cyanheads/attack-surface-mcp-server/issues/33)
- **Shodan search** exposes one opt-in 100-match page per call with query/facet-preserving continuation; empty pages terminate even with a stale total. [#31](https://github.com/cyanheads/attack-surface-mcp-server/issues/31)
- **DNS/TLS batches** accept up to 1,000 hosts, validate the complete list before I/O and process the first 50; both surfaces retain `processedCount` and exact `remainingHosts`, including per-host failures. [#34](https://github.com/cyanheads/attack-surface-mcp-server/issues/34)
