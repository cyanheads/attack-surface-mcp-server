# 0.6.0 — 2026-11-11

## Added

- **Registration attribution** includes disclosed IP allocation organizations and abuse contacts from RDAP or authoritative WHOIS. Domain lookup and map summaries include the registrar's abuse contact when disclosed. ([#48](https://github.com/cyanheads/attack-surface-mcp-server/issues/48))
- **HTTP response evidence** includes the observed CORS credentials header, findings for credentialed origin reflection and wildcard restrictions, and a finding for a final response served over plain HTTP. ([#50](https://github.com/cyanheads/attack-surface-mcp-server/issues/50))

## Changed

- **Enumeration and guidance pages** use their effective item limits. Enumeration advances past filtered candidates, guidance pages each collection independently, and map hands off the first 50 eligible hosts. Drop `oversize` from clients and follow the returned continuation offsets and `pageInstructions`. ([#47](https://github.com/cyanheads/attack-surface-mcp-server/issues/47))
- **Resolver configuration** must contain valid resolver IPs when explicitly set. Unset an empty `ATTACKSURFACE_DEFAULT_RESOLVERS` to use the defaults, or supply a valid comma-separated list.
- **Development tooling** synchronizes framework skills, changelog guidance, package and MCPB checks, and release-note validation. The package requires Bun 1.4.4 or later when run on Bun.

## Fixed

- **TLS guidance** flags hostname identity mismatches independently of chain trust in triage and posture. Map includes known certificate identity in the guidance handoff. ([#42](https://github.com/cyanheads/attack-surface-mcp-server/issues/42))
- **DNS lookups** use supplemental A and AAAA queries on the first resolver for liveness and PTR when neither address type is requested. The record maps still contain only requested types. ([#45](https://github.com/cyanheads/attack-surface-mcp-server/issues/45))
- **HTTP probes** leave audit findings empty when no final response arrives, preserve observed headers when body inspection fails, and report budget expiry separately from caller cancellation. Header names such as `__proto__` remain visible. ([#43](https://github.com/cyanheads/attack-surface-mcp-server/issues/43))
- **Malformed probe URLs** return `invalid_url` with an absolute HTTP(S) example. Disallowed schemes and targets return `blocked_target`. ([#51](https://github.com/cyanheads/attack-surface-mcp-server/issues/51))
- **Certspotter retries** fit within the remaining source deadline and surface the upstream `Retry-After` window, including when earlier pages already returned names. ([#46](https://github.com/cyanheads/attack-surface-mcp-server/issues/46))
- **WHOIS OriginAS** accepts numeric and full AS-prefixed values without treating malformed values as valid ASNs.

## Security

- **DNS isolation** uses explicit resolvers for discovery liveness and PTR, and redacts local resolver addresses from guard failures. Guarded hostnames require public A/AAAA evidence from the first configured resolver before system lookup. Use a hostname that resolves publicly there, or opt in to trusted private targets explicitly. ([#41](https://github.com/cyanheads/attack-surface-mcp-server/issues/41))
