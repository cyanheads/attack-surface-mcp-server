# 0.6.1 — 2026-11-20

## Changed

- **Vitest** uses threads under Bun to avoid an unsupported fork watchdog API.

## Fixed

- **DNS resolver configuration** uses the default list for blank or unsubstituted values and still validates configured lists. ([#53](https://github.com/cyanheads/attack-surface-mcp-server/issues/53))
- **`attacksurface_resolve_dns` and `attacksurface_inspect_tls`** trim hosts before lookup and retain the original continuation suffix. TLS inspection also propagates caller cancellation through DNS and the handshake. ([#55](https://github.com/cyanheads/attack-surface-mcp-server/issues/55), [#58](https://github.com/cyanheads/attack-surface-mcp-server/issues/58))
- **`attacksurface_probe_http`** reports WordPress and Drupal versions from the generator marker that supplied the fingerprint. ([#54](https://github.com/cyanheads/attack-surface-mcp-server/issues/54))
- **`attacksurface_map_domain`** preserves IP-attributed Shodan ports and scan dates alongside the first-success summary. Guidance receives the sorted, deduplicated port union. ([#56](https://github.com/cyanheads/attack-surface-mcp-server/issues/56))
- **Domain map text** renders upstream strings literally, including multiline findings and full URLs. ([#57](https://github.com/cyanheads/attack-surface-mcp-server/issues/57))
- **`attacksurface_recon_guidance`** requires nonblank host identifiers and treats blank TLS protocols as unknown while preserving certificate findings. ([#59](https://github.com/cyanheads/attack-surface-mcp-server/issues/59))
