# 0.3.0 — 2026-10-13

## Added

- **TLS identity** adds nullable `identityAuthorized` and `identityError`, checking the requested hostname/IP against the raw leaf independently of chain trust; mismatch and verification-error findings reach tool, map, and resource results. ([#24](https://github.com/cyanheads/attack-surface-mcp-server/issues/24))
- **HTTP `bodyInspection`** discloses observed completion, the 64,000-byte prefix limit, body failure, or no final response; usable headers and header fingerprints survive body failure, and caller cancellation propagates through map/resource aggregation. ([#25](https://github.com/cyanheads/attack-surface-mcp-server/issues/25))

## Changed

- **`timeoutMs` migration:** HTTP probes now share one total budget across DNS, redirects, headers, and body inspection instead of restarting a per-request budget. Increase the total budget where a redirect chain previously depended on several request budgets.
- **SameSite migration:** recognized cookie values now use canonical `Strict`/`Lax`/`None` instead of raw casing. Update case-sensitive comparisons; raw `Set-Cookie` headers retain the original evidence.

## Fixed

- **HTTP posture findings** use exact cookie attribute names, last SameSite values, supported framing/nosniff tokens, parsed CSP framing directives, and valid positive HSTS; ineffective values remain visible alongside raw headers. CSP findings cover framing restrictions, not general policy validity. ([#26](https://github.com/cyanheads/attack-surface-mcp-server/issues/26))
- **MCP Registry launch metadata** uses `npx` without ignored npm-script arguments and fixes the HTTP entry's `MCP_TRANSPORT_TYPE` to `http`.
- **Container and development tooling** adopt Bun `1.4.2 → 1.4.3`, prune musl-only production packages from glibc images, exclude environment/token files from build context, refresh framework skills and local verification scripts, and align CodeQL analysis categories.

## Security

- **IPv6 SSRF checks** compare parsed numeric addresses against non-public CIDRs and recognized IPv4 embeddings, blocking equivalent expanded/padded literals consistently across guard entry points. The private-target opt-out retains URL and HTTP(S) scheme validation. ([#18](https://github.com/cyanheads/attack-surface-mcp-server/issues/18))
