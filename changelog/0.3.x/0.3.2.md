# 0.3.2 — 2026-10-14

## Fixed

- **crt.sh discovery** parses newline-delimited `name_value`, retaining normalized, scoped names and disclosing malformed provider fields. ([#19](https://github.com/cyanheads/attack-surface-mcp-server/issues/19))
- **Certspotter discovery** follows issuance pages within a five-page, 15-second budget; earlier names survive later failures with explicit completeness metadata. ([#20](https://github.com/cyanheads/attack-surface-mcp-server/issues/20))
- **Discovery failures** retain address-family, blocked-target and posture errors alongside successful evidence, including filtered nonlive names; cancellation propagates and operational failure stays distinct from ordinary absence. ([#21](https://github.com/cyanheads/attack-surface-mcp-server/issues/21))
- **Standard-depth DNS posture** includes canonical records, per-resolver outcomes and propagation mismatches in maps and snapshots, with bounded host concurrency. ([#22](https://github.com/cyanheads/attack-surface-mcp-server/issues/22))
- **Candidate coverage** reserves the apex before applying caps and lists candidate/detail omissions separately, with three bounded executable retrieval examples and iteration instructions. ([#23](https://github.com/cyanheads/attack-surface-mcp-server/issues/23))
