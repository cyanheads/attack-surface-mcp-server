# 0.3.1 — 2026-10-13

## Changed

- **Desktop bundle** excludes source, tests, scripts, documentation, caches, and development configuration.

## Fixed

- **Registration targets** reject malformed CIDR prefixes and IPv6 zone identifiers before outbound requests ([#27](https://github.com/cyanheads/attack-surface-mcp-server/issues/27)).
- **RDAP IP/CIDR paths** retain literal address and prefix delimiters so IPv6 and CIDR lookups reach the bootstrap service ([#35](https://github.com/cyanheads/attack-surface-mcp-server/issues/35)).
- **WHOIS fallback** parses only recognizable authoritative responses; explicit negatives return `no_match`, while unavailable referrals or empty/unrecognized responses return `source_unavailable` with recovery guidance ([#28](https://github.com/cyanheads/attack-surface-mcp-server/issues/28)).
- **WHOIS allocations** normalize IPv4/IPv6 ranges and comma-separated allocations to exact CIDR coverage, preserving invalid text in `rawWhois` ([#29](https://github.com/cyanheads/attack-surface-mcp-server/issues/29)).
- **Evidence formatting** renders registration, HTTP, TLS, DNS, and Shodan strings literally and retains the complete raw WHOIS response in collision-safe fencing ([#30](https://github.com/cyanheads/attack-surface-mcp-server/issues/30)).
