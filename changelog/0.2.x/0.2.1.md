# 0.2.1 — 2026-08-30

## Changed

- **MCPB manifest metadata** now identifies the publisher as `cyanheads`.

## Removed

- **`toRequestContext()`** unused request-context helper was removed ([#9](https://github.com/cyanheads/attack-surface-mcp-server/issues/9)).

## Fixed

- **RDAP redirects** are followed manually with SSRF validation and a fresh five-second deadline for every hop, then fall back to WHOIS ([#1](https://github.com/cyanheads/attack-surface-mcp-server/issues/1)).
- **`attacksurface_lookup_registration`** preserves auto-detected IPv4 and IPv6 CIDR targets through RDAP lookup and formatted output ([#7](https://github.com/cyanheads/attack-surface-mcp-server/issues/7)).
- **WHOIS parsing** no longer treats whitespace-only fields as the following CRLF-delimited record ([#8](https://github.com/cyanheads/attack-surface-mcp-server/issues/8)).

## Dependencies

- `@biomejs/biome` 2.5.9 → 2.5.11
- `@types/node` ^26.2.0 → ^26.4.0
- `@vitest/coverage-istanbul` 4.1.10 → 4.1.11
