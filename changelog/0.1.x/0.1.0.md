# 0.1.0 — 2026-06-13

Initial release. Passive, non-intrusive external attack-surface mapping (EASM) for authorized, defensive assessment — reads public records and the target's own published surface only. No port scanning, exploitation, brute-forcing, or vulnerability probing.

## Added

- **`attacksurface_map_domain`** — flagship workflow. CT-log subdomain discovery → DNS liveness → (standard+) DNS records, TLS posture, HTTP headers/tech → optional RDAP/WHOIS → (thorough + Shodan key) per-IP enrichment. `depth` gating (`quick`/`standard`/`thorough`); `Promise.allSettled` fan-out degrades per-source/per-host. Synthesizes an observable-facts `assessment`, never an exploitation path.
- **`attacksurface_enumerate_subdomains`** — passive CT-log discovery (crt.sh → Certspotter → TLS-SAN fallback chain) with DNS liveness marking and per-source provenance.
- **`attacksurface_resolve_dns`** — multi-resolver A/AAAA/CNAME/MX/NS/TXT/CAA enumeration with per-resolver propagation reporting and optional reverse PTR.
- **`attacksurface_inspect_tls`** — read-only TLS handshake posture: protocol, cipher, full chain, SANs, validity, days-to-expiry, issuer, validation status, EKU. Inspects invalid/expired/self-signed certs without failing.
- **`attacksurface_probe_http`** — single passive GET following redirects; security-header audit (HSTS/CSP/X-Frame-Options/cookie flags/CORS reflection) and evidence-bound tech fingerprint.
- **`attacksurface_lookup_registration`** — RDAP (302-follow, 5s deadline) with WHOIS port-43 fallback for domains and IP/CIDR netblocks.
- **`attacksurface_lookup_host`** — Shodan single-host lookup and faceted search. Requires `SHODAN_API_KEY`; returns a typed `source_unavailable` when unset while the rest of the server keeps working.
- **`attacksurface_recon_guidance`** — offline synthesis over passed-in findings into a prioritized defensive review plan plus pre-filled follow-up calls, including cross-server CVE lookups (`nist-nvd`, `osv-advisory`).
- **`attacksurface://surface/{domain}`** resource — read-once standard-depth surface snapshot; the same data is reachable via `map_domain`.
- **SSRF guard** (`src/utils/ssrf-guard.ts`) — `assertSafeDomain` / `assertSafeUrl` / `assertSafeResolverIp` reject private, loopback, link-local, cloud-metadata, and reserved ranges (IPv4 + IPv6) before every outbound connection. Opt out for trusted internal assessment via `ATTACKSURFACE_ALLOW_PRIVATE_TARGETS=true`.
- **Services** — `ct`, `dns`, `tls`, `http`, `registration`, `shodan` (init/accessor pattern). External-API services carry `withRetry` backoff and parse classification; crt.sh/Certspotter/RDAP degrade gracefully.
- **Config** — `SHODAN_API_KEY`, `CERTSPOTTER_API_KEY`, `ATTACKSURFACE_DEFAULT_RESOLVERS`, `ATTACKSURFACE_HTTP_USER_AGENT`, `ATTACKSURFACE_MAX_SUBDOMAINS`, `ATTACKSURFACE_RDAP_BOOTSTRAP_URL`, `ATTACKSURFACE_ALLOW_PRIVATE_TARGETS`. All optional — the keyless core boots with an empty environment.
