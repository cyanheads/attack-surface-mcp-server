# 0.1.2 — 2026-08-21

## Changed

- **`@cyanheads/mcp-ts-core` ^0.10.6 → ^0.12.3** — upstream CT-log and Shodan REST calls moved onto the framework's fetch/retry layer: centralized timeouts, expected-status handling, and `Retry-After` honoring.
- **Per-item error fields renamed** to name their failure domain: `attacksurface_inspect_tls` `results[].error` → `handshakeError`; `attacksurface_probe_http` `error` → `transportError`; `attacksurface_resolve_dns` `error` → `queryError` / `lookupError` / `hostError`; `attacksurface_enumerate_subdomains` `sourceStatuses[].error` → `sourceError`. Clients reading structured output must update field names.
- **crt.sh overload responses (HTTP 502/503/504) and Certspotter free-tier 429s** are expected statuses logged at debug, not errors; Certspotter keeps its remediation hint and `retryAfter` across retries.
- **`attacksurface_lookup_host`**: unscanned Shodan targets (HTTP 404) return the typed `no_data` error instead of a raw upstream failure.

## Added

- **Reconciled test suite** under `tests/`: fetch-faked unit tests per service, integration tests per tool, offline definition-catalog smoke checks, and fast-check fuzz projects, plus a `test:coverage` script.
- **Supply-chain guards** (`bunfig.toml`): installs reject packages published within the last 3 days (the framework is exempt) and every install is scanned by Socket.
- **Docker image**: `oven/bun:1.4.0` base, BuildKit cache mounts, and `--omit=peer` production installs that drop unused optional peer tiers.
- **Community health files**: `CODE_OF_CONDUCT`, `CONTRIBUTING`, `SECURITY`, and `FUNDING` under `.github/`, plus `.gitattributes` line-ending rules.

## Fixed

- **`docs/tree.md` generation** honors directory-only ignore patterns (`/data/`, `.claude/`), so ignored directories no longer leak into the generated tree.
